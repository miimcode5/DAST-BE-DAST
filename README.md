# دست‌به‌دست (DAST BE DAST) — نسخه ۱.۰.۰

**توان ما، کنار هم معنا پیدا می‌کند.**  
*«گاهی چیزی که برای تو ساده است، می‌تواند مشکل بزرگی را برای دیگری حل کند.»*

«دست‌به‌دست» یک پلتفرم اجتماعی کمک متقابل و مشارکت مردمی (وب‌اپلیکیشن پیش‌رونده / PWA) به زبان فارسی و راست‌چین (RTL) است که افراد نیازمند کمک را به داوطلبان و افراد دارای مهارت متصل می‌کند. نقطه شروع فعالیت از **استان خراسان جنوبی** است و زیرساخت آن قابلیت گسترش به تمام استان‌های ایران را دارد.

---

## قابلیت‌های کلیدی نسخه ۱.۰.۰

- **احراز هویت واقعی با Supabase Auth**: ثبت‌نام، ورود، بازیابی رمز عبور، تنظیم رمز جدید (همراه با ثبت اعلان امنیتی) و خروج امن.
- **پروفایل کاربری و مهارت‌ها**: مدیریت نام نمایشی، تصویر پروفایل (در Supabase Storage)، معرفی کوتاه، استان، شهر، محدوده تقریبی فعالیت، مهارت‌ها و نمایش تعداد کمک‌های تأییدشده.
- **ثبت و مدیریت درخواست کمک**: در ۸ دسته‌بندی (کمک‌های روزمره، آموزش و یادگیری، تعمیرات و خدمات فنی، اهدای وسایل، کمک به سالمندان، فعالیت‌های داوطلبانه، کمک‌های فوری و محلی، خدمات تخصصی و مهارتی) و ۵ نوع کمک، همراه با آپلود تصویر اختیاری.
- **موتور پیشنهادگر محلی (قانون‌محور)**: تحلیل خودکار متن درخواست در سمت کاربر برای پیشنهاد دسته‌بندی، نوع کمک، بهبود عنوان، تشخیص اطلاعات ناقص و هشدار حفظ حریم خصوصی (بدون وابستگی به API خارجی).
- **جست‌وجو و فیلتر پیشرفته**: جست‌وجو در عنوان، توضیحات و محدوده + فیلتر دسته‌بندی، شهر، نوع کمک، وضعیت و مرتب‌سازی + تطبیق محلی با شهر و مهارت داوطلب.
- **اعلام آمادگی داوطلبان و جریان دوطرفه**:
  - ثبت «من می‌توانم کمک کنم» از طریق تابع امن دیتابیس (`submit_volunteer_response`)
  - جلوگیری از اعلام آمادگی برای درخواست خود، جلوگیری از ثبت تکراری (`UNIQUE(request_id, volunteer_id)`) و جلوگیری خودکار هنگام مسدودیت دوطرفه
  - پذیرش/رد داوطلب، شروع همکاری، اعلام انجام از طرف داوطلب و تأیید نهایی تکمیل کمک توسط درخواست‌کننده
- **گفت‌وگوی خصوصی و لحظه‌ای (Real-time Private Chat)**:
  - ایجاد خودکار گفت‌وگوی خصوصی میان درخواست‌کننده و هر داوطلب هنگام ثبت اعلام آمادگی (گفت‌وگوی مجزا و مستقل برای هر داوطلب)
  - ارسال و دریافت پیام به‌صورت لحظه‌ای با **Supabase Realtime** بدون نیاز به رفرش صفحه
  - صفحه اختصاصی «پیام‌ها» با مرتب‌سازی بر اساس جدیدترین پیام، نشانگر پیام‌های خوانده‌نشده در ناوبری موبایل/دسکتاپ و ثبت وضعیت خوانده‌شدن (`read_at`)
  - همگام‌سازی کامل چت با چرخه درخواست (حفظ تاریخچه هنگام تکمیل، لغو یا مسدودسازی و کنترل دسترسی ارسال در لایه دیتابیس)
- **مرکز اعلان‌های لحظه‌ای (`/notifications`)**:
  - ثبت خودکار اعلان‌ها در سمت دیتابیس برای رویدادهای واقعی (پیام جدید، پیشنهاد کمک، پذیرش/رد همکاری، شروع و اعلام انجام، تکمیل کمک، لغو درخواست/انصراف داوطلب، خوش‌آمدگویی و تغییر رمز عبور)
  - شمارنده زنده خوانده‌نشده در هدر و منوی موبایل، فیلتر همه/خوانده‌نشده، علامت‌گذاری تکی یا همگانی، و هماهنگی خودکار با باز شدن چت
- **ایمنی، مسدودسازی کاربر و گزارش تخلف + پنل نظارت (`/moderation`)**:
  - مسدود کردن و رفع مسدودیت کاربر از صفحه گفت‌وگو یا تنظیمات (`user_blocks`) با اعمال سخت‌گیرانه در سرور (بستن چت و ثبت اعلام آمادگی متقابل)
  - گزارش درخواست‌های نامناسب (`content_reports`) و گزارش گفت‌وگو (`conversation_reports`)
  - پنل نظارت `/moderation` با بررسی نقش واقعی (`admin`/`moderator`) سمت سرور از طریق `is_moderator_or_admin()`
  - محدودیت دسترسی مهمان (`anon`) روی جدول‌های خصوصی و `profiles` و نمایش عمومی صرفاً از طریق نمای امن `public_help_requests_feed`
- **فعالیت‌های من و ذخیره‌سازی**: مدیریت درخواست‌های من، اعلام آمادگی‌ها، همکاری‌های در حال انجام، تکمیل‌شده‌ها، ذخیره‌شده‌ها و لغوشده‌ها.
- **آمار واقعی مشارکت و زنجیره مهربانی**: نمایش آمار زنده بدون داده‌های ساختگی و نمایش پیوندهای واقعی کمک‌های تأییدشده.
- **PWA و قابلیت نصب روی اندروید + حالت آفلاین**:
  - `manifest.webmanifest` کامل با آیکون‌های استاندارد و `maskable`
  - فونت رسمی فارسی **Pinar FD** (وزن‌های `300` تا `900`) و پالت ۸ رنگ رسمی پیش‌کش‌شده در Service Worker + صفحه آفلاین اختصاصی (`public/offline.html`)
  - ذخیره‌سازی محلی در IndexedDB (شامل کش درخواست‌ها، آمار، پروفایل، گفت‌وگوها و اعلان‌ها + صف همگام‌سازی درخواست‌های آفلاین).

## فناوری‌های استفاده‌شده

- **Frontend:** React 19, TypeScript, Vite 6, Tailwind CSS v4, React Router v7, Lucide Icons
- **Typography:** فونت محلی `Pinar FD` (`public/fonts/pinar/Pinar-FD-*.woff2`) با فال‌بک `Vazirmatn`
- **Backend & Database:** Supabase (PostgreSQL 17, Supabase Auth, Supabase Realtime, Supabase Storage, Row Level Security & `SECURITY DEFINER` RPCs)
- **PWA & Offline:** `vite-plugin-pwa` (Workbox), Web App Manifest, Service Worker, `idb` (IndexedDB)
- **Testing:** Vitest

## راهنمای راه‌اندازی محلی

1. نصب وابستگی‌ها:
   ```bash
   npm install
   ```
2. ایجاد فایل `.env.local` بر اساس `.env.example` و قرار دادن آدرس و کلید عمومی (`anon`) پروژه Supabase:
   ```env
   VITE_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
   VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
   ```
   > **تذکر امنیتی:** هرگز کلید `service_role` یا کلیدهای محرمانه را در فایل‌های Frontend یا مخزن Git قرار ندهید.

3. اجرای Migrationهای پوشه `supabase/migrations/` روی پروژه Supabase (به ترتیب زمانی).
4. اجرای محیط توسعه یا پیش‌نمایش PWA:
   ```bash
   npm run dev
   ```
   یا برای ساخت نسخه نهایی PWA و آزمایش Service Worker:
   ```bash
   npm run build
   npm run preview
   ```

5. اجرای تست‌ها و بررسی تایپ‌ها:
   ```bash
   npm run typecheck
   npm test
   ```
