# دست‌به‌دست (DAST BE DAST)

**توان ما، کنار هم معنا پیدا می‌کند.**  
*«گاهی چیزی که برای تو ساده است، می‌تواند مشکل بزرگی را برای دیگری حل کند.»*

«دست‌به‌دست» یک پلتفرم اجتماعی کمک متقابل و مشارکت مردمی (وب‌اپلیکیشن پیش‌رونده / PWA) به زبان فارسی و راست‌چین (RTL) است که افراد نیازمند کمک را به داوطلبان و افراد دارای مهارت متصل می‌کند. نقطه شروع فعالیت از **استان خراسان جنوبی** است و زیرساخت آن قابلیت گسترش به تمام استان‌های ایران را دارد.

---

## قابلیت‌های کلیدی نسخه اول (MVP)

- **احراز هویت واقعی با Supabase Auth**: ثبت‌نام، ورود، بازیابی رمز عبور، تنظیم رمز جدید و خروج امن.
- **پروفایل کاربری و مهارت‌ها**: مدیریت نام نمایشی، تصویر پروفایل (در Supabase Storage)، معرفی کوتاه، استان، شهر، محدوده تقریبی فعالیت، مهارت‌ها و نمایش تعداد کمک‌های تأییدشده.
- **ثبت و مدیریت درخواست کمک**: در ۸ دسته‌بندی (کمک‌های روزمره، آموزش و یادگیری، تعمیرات و خدمات فنی، اهدای وسایل، کمک به سالمندان، فعالیت‌های داوطلبانه، کمک‌های فوری و محلی، خدمات تخصصی و مهارتی) و ۵ نوع کمک، همراه با آپلود تصویر اختیاری.
- **موتور پیشنهادگر محلی (قانون‌محور)**: تحلیل خودکار متن درخواست در سمت کاربر برای پیشنهاد دسته‌بندی، نوع کمک، بهبود عنوان، تشخیص اطلاعات ناقص و هشدار حفظ حریم خصوصی (بدون وابستگی به API خارجی).
- **جست‌وجو و فیلتر پیشرفته**: جست‌وجو در عنوان، توضیحات و محدوده + فیلتر دسته‌بندی، شهر، نوع کمک، وضعیت و مرتب‌سازی + تطبیق محلی با شهر و مهارت داوطلب.
- **اعلام آمادگی داوطلبان و جریان دوطرفه**:
  - ثبت «من می‌توانم کمک کنم» از طریق تابع امن دیتابیس (`submit_volunteer_response`)
  - جلوگیری از اعلام آمادگی برای درخواست خود و جلوگیری از ثبت تکراری (`UNIQUE(request_id, volunteer_id)`)
  - پذیرش/رد داوطلب، شروع همکاری، اعلام انجام از طرف داوطلب و تأیید نهایی تکمیل کمک توسط درخواست‌کننده
- **فعالیت‌های من و ذخیره‌سازی**: مدیریت درخواست‌های من، اعلام آمادگی‌ها، همکاری‌های در حال انجام، تکمیل‌شده‌ها، ذخیره‌شده‌ها و لغوشده‌ها.
- **آمار واقعی مشارکت و زنجیره مهربانی**: نمایش آمار زنده بدون داده‌های ساختگی و نمایش پیوندهای واقعی کمک‌های تأییدشده.
- **PWA و قابلیت نصب روی اندروید + حالت آفلاین**:
  - `manifest.webmanifest` کامل با آیکون‌های استاندارد و `maskable`
  - Service Worker برای کش فایل‌های هسته و فونت محلی `Vazirmatn` + صفحه آفلاین اختصاصی (`public/offline.html`)
  - ذخیره‌سازی محلی در IndexedDB برای مشاهده آفلاین و صف همگام‌سازی خودکار درخواست‌های ثبت‌شده در حالت آفلاین با وضعیت «در انتظار همگام‌سازی».

## فناوری‌های استفاده‌شده

- **Frontend:** React 19, TypeScript, Vite 6, Tailwind CSS v4, React Router v7, Lucide Icons
- **Typography:** فونت محلی `@fontsource/vazirmatn` (بدون وابستگی اجباری به سرویس خارجی)
- **Backend & Database:** Supabase (PostgreSQL 17, Supabase Auth, Supabase Storage, Row Level Security & `SECURITY DEFINER` RPCs)
- **PWA & Offline:** `vite-plugin-pwa` (Workbox), Web App Manifest, Service Worker, `idb` (IndexedDB)
- **Testing:** Vitest

## راهنمای راه‌اندازی محلی

1. نصب وابستگی‌ها:
   ```bash
   npm install
   ```
2. ایجاد فایل `.env.local` بر اساس `.env.example` و قرار دادن آدرس و کلید عمومی (`anon`) پروژه Supabase:
   ```env
   VITE_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
   VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
   ```
   > **تذکر امنیتی:** هرگز کلید `service_role` یا کلیدهای محرمانه را در فایل‌های Frontend یا مخزن Git قرار ندهید.

3. اجرای Migrationهای پوشه `supabase/migrations/` روی پروژه Supabase (به ترتیب شماره‌گذاری).
4. اجرای محیط توسعه یا پیش‌نمایش PWA:
   ```bash
   npm run dev
   ```
   یا برای ساخت نسخه نهایی PWA و آزمایش Service Worker:
   ```bash
   npm run build
   npm run preview
   ```

5. اجرای تست‌ها:
   ```bash
   npm run typecheck
   npm test
   ```
